## 🛒 OneCart.com

### Full Stack MERN E-Commerce Platform

OneCart.com is a full-stack e-commerce platform built using the **MERN Stack — MongoDB, Express.js, React.js, and Node.js**.

The project focuses on providing a complete online shopping experience with a modern React frontend, Node.js/Express.js backend APIs, MongoDB database integration, authentication, product management, cart functionality, and order management.

`MongoDB` `Express.js` `React.js` `Node.js`

`JavaScript` `HTML5` `CSS3` `REST APIs` `JWT Authentication`
